# Shubham Jha | Portfolio

A premium, single-page developer portfolio designed to showcase Full Stack Java projects, technical skills, and academic achievements. Built with a modern "Luxury Editorial" aesthetic featuring deep charcoal backgrounds and metallic gold accents.

## 🚀 Features

* **Zero Dependencies:** Built entirely with vanilla HTML, CSS, and JavaScript. No heavy frameworks required.
* **Luxury Theme:** A sophisticated dark color palette (`#0a0a0a` background with `#D4AF37` gold accents) designed to stand out to enterprise and top-tier tech recruiters.
* **Custom Cursor Integration:** Smooth, physics-based custom cursor with hover states (automatically disabled on mobile devices for accessibility).
* **Performance Optimized:** Uses `IntersectionObserver` for seamless, lag-free scroll reveal animations and number counters.
* **Fully Responsive:** Adapts flawlessly across desktop, tablet, and mobile breakpoints using CSS Grid and Flexbox.
